# ORBIA NFC ambient media

Place optimized hero assets here:

- `orbia-nfc-ambient.webm` — preferred (720×1280, dark, low contrast, compressed)
- `orbia-nfc-ambient.mp4` — H.264 fallback (720×1280)
- `orbia-nfc-poster.jpg` — required poster frame (same framing as video)

If missing, the experience uses CSS starfield + gradient fallback and does not break.
